Leia-me

Regras: 1 gato por cor, 1 por linha e 1 por coluna, e os gatos não podem se tocar. Como no anúncio, considerei que “tocar” inclui a diagonal. Se você quiser proibir só lado a lado, é uma linha para mudar.
Como jogar: toque uma vez para marcar ✕, duas vezes para colocar o gato e três para limpar.
Vidas: são 3 corações. Se você colocar um gato no lugar errado, perde uma vida.
Placar e botões: o contador (3/8) mostra quantos gatos você já colocou. Há também o botão Dica, que pisca uma casa certa, e o Recomeçar.
Fases: começam em 5×5 e chegam a 8×8 a partir do nível 8. Cada fase tem uma única solução e o nível fica salvo no navegador.
